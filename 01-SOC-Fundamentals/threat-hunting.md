# Threat Hunting

## 1. Introduction

Threat Hunting is the process of actively searching for hidden threats and malicious activities within an organisation's systems and network.

Security tools such as antivirus and other security solutions may not detect every attack. Some attackers develop techniques or malware that can bypass existing security defences.

Threat hunting helps security teams search for these hidden threats before they cause further damage.

## 2. Why Is Threat Hunting Important?

Traditional security tools help detect known or suspicious activities and generate alerts. However, not every malicious activity is automatically detected.

Threat hunting is important because it helps organisations:

- Identify threats that may have bypassed antivirus software.
- Discover hidden malicious activities.
- Identify suspicious behaviour that may not have generated an alert.
- Improve the organisation's overall security posture.

## 3. How Does Threat Hunting Work?

Threat hunting involves actively investigating systems and network activities to identify possible hidden threats.

A basic approach includes:

1. **Identify suspicious activity:** Look for unusual behaviour or indicators that may suggest a security threat.
2. **Investigate:** Examine relevant system and network information.
3. **Identify hidden threats:** Determine whether suspicious activity indicates malicious behaviour that existing security tools may have missed.
4. **Take appropriate action:** Report or escalate confirmed findings and follow the organisation's incident response procedures.

## 4. Practical Example

Imagine an attacker creates malware that bypasses an organisation's antivirus software.

The antivirus does not generate an alert, so the malicious activity remains undetected.

A threat hunter investigates unusual activities within the organisation's environment and discovers suspicious behaviour associated with the malware.

The security team can then investigate the finding and take appropriate action to protect the affected systems.

## 5. Threat Hunting in a SOC

Threat hunting is a proactive security activity performed to identify threats that may not have been detected by existing security tools.

It complements security monitoring and automated alert detection.

While security tools help generate alerts based on configured rules and detections, threat hunting involves actively searching for suspicious activities that may otherwise remain unnoticed.

## 6. Threat Hunting vs Threat Intelligence

| Threat Hunting | Threat Intelligence |
|---|---|
| Actively searches for hidden threats within an organisation's environment. | Collects and analyses information about potential threats and attacks. |
| Focuses on identifying malicious activities that may have bypassed security defences. | Helps security teams understand threats and strengthen defences. |
| Primarily supports proactive threat discovery. | Supports proactive security planning and defence improvements. |

## 7. Key Takeaway

Threat hunting helps organisations discover hidden threats that may have bypassed antivirus software or other existing security defences.

**Remember:** Security tools generate alerts, while threat hunting actively searches for threats that may otherwise go unnoticed.
