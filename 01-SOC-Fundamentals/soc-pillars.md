# Three Pillars of a Security Operations Centre (SOC)

## 1. Introduction

A Security Operations Centre (SOC) relies on three important components to monitor, detect, and respond to cybersecurity threats.

These components are known as the **three pillars of a SOC**:

1. People
2. Process
3. Technology

All three pillars work together to support effective security operations.

## 2. People

People are the security professionals responsible for carrying out SOC activities.

Different team members have different responsibilities, depending on their roles and expertise.

Examples include:

- **SOC Analysts:** Monitor security alerts, investigate suspicious activities, and escalate incidents.
- **Incident Responders:** Handle detected security incidents and help restore affected systems.
- **Threat Analysts:** Collect and analyse information about potential threats.
- **Security Engineers:** Implement and maintain security technologies.
- **SOC Managers:** Coordinate SOC operations and manage team activities.

A SOC depends on collaboration between these professionals to protect an organisation's systems and information.

## 3. Process

Processes are the procedures and methods followed by the SOC team to manage security activities.

They help ensure that security tasks are performed in a structured and consistent manner.

Examples include:

- **Security Monitoring:** Continuously monitoring systems and networks for suspicious activities.
- **Incident Response:** Following defined steps to handle detected security incidents.
- **Threat Intelligence:** Collecting information about threats and attacks to strengthen organisational defences.
- **Threat Hunting:** Proactively searching for threats that may have bypassed existing security controls.
- **Threat Modelling:** Identifying potential threats and understanding how they could affect systems.
- **Playbooks:** Documenting procedures and actions to follow during specific security incidents.
- **SOAR:** Using Security Orchestration, Automation and Response to automate and coordinate security operations.

Following defined processes helps the SOC team respond to security events in an organised way.

## 4. Technology

Technology refers to the security tools and solutions used by SOC professionals to monitor systems, detect threats, and support incident response.

Examples include:

### SIEM – Security Information and Event Management

SIEM tools collect logs from different devices and systems, analyse security events, and generate alerts based on configured rules and correlations.

### IDS – Intrusion Detection System

An IDS monitors network or system activities to identify suspicious behaviour and generate alerts.

### IPS – Intrusion Prevention System

An IPS monitors network traffic and can take action to block or prevent detected malicious activity.
