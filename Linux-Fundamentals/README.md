# Linux Fundamentals – Hands-on Learning Portfolio

## Project Overview

This project documents my journey of learning Linux fundamentals through practical exercises using Ubuntu Linux and Kali Linux.

The objective is to develop Linux command-line skills and understand how Linux systems are administered, monitored and investigated in a cybersecurity environment.

## Learning Objectives

- Understand Linux fundamentals and file system structure.
- Navigate directories and manage files.
- Work with Linux commands and command-line options.
- Understand users, groups and file permissions.
- Monitor processes and system resources.
- Perform basic network troubleshooting.
- Understand Linux system and authentication logs.
- Develop practical skills relevant to Junior SOC Analyst responsibilities.
